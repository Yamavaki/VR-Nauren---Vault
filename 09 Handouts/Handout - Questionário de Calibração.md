**QUESTIONÁRIO DE CALIBRAÇÃO DE AVATAR** ◇ Halden Systems
*Responda com sinceridade. Não há respostas erradas.*

1. Nome completo: ______________________

5. Descreva um lugar onde você se sentiu em casa, em uma frase: ______________________
6. Qual é a coisa que você **não** faria nem para vencer? ______________________
7. **Quais são as suas duas cores favoritas?** ________ e ________
8. Você já sonhou com um lugar onde nunca esteve? ( ) sim ( ) não ( ) prefiro não responder
9. Se alguém lá dentro chamar você pelo nome, num momento de perigo, você acha que **sentiria**? ( ) sim ( ) não ( ) que pergunta é essa?

*Obrigado. Sua calibração será concluída durante o primeiro mergulho.*

- **Pergunta 8** "sim" + gancho de origem 8 = esse PJ tem algo especial. Decida depois.
- **Pergunta 9** é o 1º Nó escondido: um nativo (a [[Tilde]]?) gritando o nome do PJ num momento de perigo.
