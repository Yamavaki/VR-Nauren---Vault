# The Simulation — Vault do Mestre (Nauren RPG)

Vault do Obsidian da campanha **"The Simulation"** (título provisório), no sistema [Nauren RPG](https://github.com/Yamavaki/Nauren-RPG).

> ⚠️ **Spoilers.** Tudo aqui é material do mestre. Jogadores: não leiam.

**Como abrir:** no Obsidian, *Open folder as vault* e escolha esta pasta. Comece pela nota `00 Início/Home.md`.

| Pasta | Conteúdo |
|---|---|
| 00 Início | painel, decisões (canon), perguntas em aberto, nomes |
| 01 Referência | Campaign Brief e os guias (RPG, Style, Character) |
| 02 Regras da Casa | fichas humano/avatar, Sincronia e Demãos, Morte e Retorno |
| 03 Mundo | Terra (Meridia, a Aster) e Naurien (a Marca de Vael) |
| 04 NPCs | uma nota por NPC |
| 05 Arcos | Arco 1 e bestiário |
| 06 Sessões | Sessão 0 e Sessão 1 |
| 07 Pistas e Segredos | pistas do arco, escada de revelações |
| 08 Relógios | relógios das ameaças |
| 09 Handouts | material para entregar aos jogadores |
| 10 Diário | diário de sessões, teorias dos jogadores |
| _Templates | modelos de NPC, sessão e local |
